# API Stability Reviewer

Represent FLETCH, MDCROP, WITNESS, and future consumers of the neutral context family.

## Lens - What to Verify

- public crate responsibilities remain distinct;
- stable APIs are not claimed before the repository's stated maturity gate;
- compatibility changes include fixtures and migration evidence;
- product/provider integrations remain at the edges.

Block accidental public promises or family-boundary breakage without migration proof.
