Receive without Git

Prerequisite: Python 3.11+ with its standard library, including lzma. Inspect and trust receiver.zip before unpacking its three Python modules and full license texts into a new helper directory. Verification uses no Git, Cargo, pip or network and executes no downloaded code. From the helper directory:

python -I -S -B receive-source.py --archive /downloads/source.tar.xz --sha256 @@SOURCE_SHA@@ --output /new/LATTICE --protect /compiled-target

Use a new output outside the download, helper and compiled-target directories. The receiver bounds archive resources, verifies the complete Git commit/tree/file/mode inventory and rejects unsafe paths, links and existing destinations before writing. POSIX disk modes are checked on POSIX; Windows retains the original mode inventory without claiming equivalent ACLs.

Rebuild with original offline inputs

Install Rust 1.95.0 including wasm32-unknown-unknown, wasm-bindgen CLI 0.2.127 and Python 3.11+ separately. Complete original archives for all 26 locked dependencies, their 981 original files and original grant texts are included. No compiler or package-manager installer is redistributed. Review received code before building it.

The original METIS dependency declares branch=master and locks commit 78ae34090e043e79a206f2daffaa3889389b4790. Its original commit/tree/blob/mode identity is checked; offline source replacement preserves that source selector and never resolves the branch online. Manifests and the lock are unchanged. This optional crop dependency does not decide semantic closure.

From the received source, choose three new directories outside it for dependency inputs, Cargo home and compiled output:

python tools/build-pages.py --inputs /new/lattice-inputs --cargo-home /new/lattice-home --target /new/lattice-target

The builder restores and reads back owned inputs, checks locked offline metadata, remaps diagnostic paths and writes a new dist/LATTICE. The complete delivery must stay below 5,000,000 bytes. Serve with python -m http.server 8771 --directory dist and open http://localhost:8771/LATTICE/. Direct file opening is not supported.

Validate the result

Node 22, locked npm development dependencies and Playwright Chromium are additional validation prerequisites. The algebra check covers every 32 × 32 × 8 × 2 bounded combination plus 14 portable typed invalid controls: complete native/WASM strings, receipts, frontiers and errors must match the frozen original byte stream. Raw JavaScript coercions remain separate observations.

python tools/check-algebra.py --site dist/LATTICE --output /new/algebra-proof --inputs /new/lattice-inputs --cargo-home /new/lattice-home --target /new/lattice-target
python tools/check-source-replay.py --site dist/LATTICE --output /new/source-replay --browser

The second command receives the actual delivered source outside Git, uses new inputs/home and an initially absent compiled target, reproduces every published file/manifest, then runs native tests, formatting/lint, all 16,398 algebra controls and the browser suite. It reuses installed tools and original-checkout npm/browser prerequisites. Same-platform byte equality is required; cross-platform compiler-byte identity is not promised.
